Autumn Solutions - LedgerFlow Identity Architecture

SAML 2.0 Federation
User
  -> LedgerFlow custom SAML service provider
  -> Microsoft Entra ID authentication
  -> signed SAML assertion
  -> LedgerFlow validates signing certificate, issuer, audience, NameID, and claims

The Microsoft Entra SAML Toolkit was used only as an independent troubleshooting
and validation harness. It was not the production destination in the completed lab.

OpenID Connect and OAuth 2.0
LedgerFlow OIDC client
  -> Microsoft Entra ID authorize endpoint
  -> authorization code
  -> token exchange using PKCE
  -> ID token for authentication
  -> delegated access token
  -> Microsoft Graph /me using User.Read

SCIM 2.0 Provisioning
Microsoft Entra provisioning service
  -> HTTPS through a temporary Cloudflare Tunnel
  -> custom LedgerFlow SCIM API
  -> persistent user store

Assignment creates a user.
Attribute changes update the user.
Unassignment disables the user by setting active=false.
